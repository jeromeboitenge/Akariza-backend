🚀 DEPLOYMENT STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. PUSH TO GITHUB
   ─────────────────────────────────────────────────────────────────────────
   cd /home/boitenge/Desktop/akariza/backend
   git add .
   git commit -m "Add Render deployment configuration"
   git push origin main

2. CREATE RENDER ACCOUNT
   ─────────────────────────────────────────────────────────────────────────
   Go to: https://render.com
   Sign up with GitHub

3. CREATE DATABASE
   ─────────────────────────────────────────────────────────────────────────
   Dashboard → New + → PostgreSQL
   
   Settings:
   • Name: akariza-db
   • Database: akariza
   • User: akariza_user
   • Region: Oregon (or closest)
   • Plan: Free
   
   Click "Create Database"
   Copy the "Internal Database URL"

4. CREATE WEB SERVICE
   ─────────────────────────────────────────────────────────────────────────
   Dashboard → New + → Web Service
   
   Connect GitHub repository
   
   Settings:
   • Name: akariza-backend
   • Region: Same as database
   • Branch: main
   • Root Directory: (leave blank or "backend" if monorepo)
   • Runtime: Node
   • Build Command: npm install && npx prisma generate && npm run build
   • Start Command: npm run start:prod
   • Plan: Free

5. ADD ENVIRONMENT VARIABLES
   ─────────────────────────────────────────────────────────────────────────
   Click "Advanced" → Add Environment Variables:
   
   NODE_ENV=production
   PORT=5000
   DATABASE_URL=<paste Internal Database URL from step 3>
   JWT_SECRET=<generate random 32+ char string>
   JWT_REFRESH_SECRET=<generate random 32+ char string>
   JWT_EXPIRES_IN=15m
   JWT_REFRESH_EXPIRES_IN=7d
   
   Generate secrets:
   openssl rand -base64 32

6. DEPLOY
   ─────────────────────────────────────────────────────────────────────────
   Click "Create Web Service"
   Wait 5-10 minutes for deployment

7. RUN MIGRATIONS
   ─────────────────────────────────────────────────────────────────────────
   Once deployed, go to Shell tab:
   
   npx prisma migrate deploy
   
   (Optional) Seed data:
   npm run prisma:seed

8. TEST DEPLOYMENT
   ─────────────────────────────────────────────────────────────────────────
   Your API: https://akariza-backend.onrender.com
   
   Test:
   curl https://akariza-backend.onrender.com/health
   
   Docs:
   https://akariza-backend.onrender.com/api/v1/docs

⚠️  FREE TIER LIMITATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• Service spins down after 15 minutes of inactivity
• First request after spin-down takes ~30 seconds (cold start)
• Database expires after 90 days (upgrade to keep)
• 750 hours/month (enough for 1 service)

Upgrade to Starter ($7/month) for:
• No spin-down
• Persistent database
• Better performance

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Build fails:
→ Check Logs tab for errors
→ Verify package.json scripts
→ Ensure all dependencies in package.json

Service won't start:
→ Check environment variables
→ Verify DATABASE_URL is correct
→ Test database connection in Shell

Migrations fail:
→ Run manually in Shell: npx prisma migrate deploy
→ Check database is ready

Slow response:
→ Normal on free tier (cold start)
→ Upgrade to paid plan for instant response
